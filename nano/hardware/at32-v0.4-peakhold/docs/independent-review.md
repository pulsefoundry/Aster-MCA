# AT32 v0.4 两板独立接口、合装与来源审查

审查日期：2026-11-12。只读读取权威 PCB、原生导出证据及制造文件；未修改 CAD，未访问硬件。本报告的唯一新增工作文件为本文件。

**本轮未发现 P1 电气接口或合装几何错误。**22 个模块接口在编号、网络与中心位置上全部一致；模块覆盖区没有底板元件侵入；USB 公头突出方向、固定孔与 SMA 区域符合当前封装基准。此结论针对设计文件，不代表已完成实物连接器配合、峰值保持动态性能或量产放行。

## 合装几何和遮挡

- 实际板框为核心 26 × 20 mm、底板 60 × 32 mm；两个 PCB 的名义板厚均为 1.6 mm。核心安装后板体范围为 x8–34/y6–26 mm；叠板名义基材总厚度为 3.2 mm，另加焊层和顶面器件高度。
- 两板均没有底面器件。逐器件检查底板实际 `F.Fab` 包络，没有元件进入核心板体投影；核心器件位于模块上方，不与底板右侧模拟器件或左侧 USB 相撞。M1 没有 courtyard，因此本项使用实际板体矩形独立检查，不能仅由普通 DRC 零 courtyard 冲突推导。
- USB J1 位于 (-3.8,16) mm、180°。封装 `F.Fab` 几何线中心约 x−14.70…6.60 mm，前端向底板左侧突出约 14.70 mm；没有把公头插入端留在板内。其最右信号焊盘到 x7.10 mm，与模块 x8 mm 板边相隔 0.90 mm；USB courtyard 右缘线中心约 x7.60 mm，与模块板边相隔约 0.40 mm。该数值仅支持既定封装，不能代替实际替代连接器的尾部外形测量。
- USB 两个外壳固定槽均保留：孔中心 (3.1,10.3)/(3.1,21.7) mm，槽 2.5 × 0.9 mm；两个 NPTH 定位孔中心 (3.1,13.7)/(3.1,18.3) mm，孔径 1.1 mm。四个信号焊盘中心均 x5.85 mm，y 分别为 19.5/17/15/12.5 mm，对应 VBUS/D−/D+/GND。
- SMA J2 中心 (55,16) mm；信号孔 1.5 mm，四个 1.7 mm 地孔中心为 x52.46/57.54、y13.46/18.54 mm，形成 5.08 mm 方阵。封装 courtyard 线中心范围 x50.83–59.17/y11.83–20.17 mm，距右板边约 0.83 mm；没有与模块、比较器或保持部分件体重叠。邻近 C112 的 courtyard 到 SMA courtyard 的垂直间隙约 0.42 mm；使用体积更大的替代 SMA 时需重新核对。
- J3 G-S-G 三孔位于 y25 mm、x52.46/55/57.54 mm，与 SMA 焊盘和器件区分开。J2/J3 是同一输入的两种接法，不允许两台主动源同时驱动。

几何判断来自封装 `F.Fab`/`F.CrtYd` 与实际焊盘，不是完整三维公差分析。连接器金属外壳、焊脚实际突出高度及焊接后平整度仍需实物核验。

## 两板贴合面的裸铜和阻焊

两个权威 PCB 均设置正反面过孔 tenting。独立读取 KiCad 制造输出：

- 核心 `*-B_Mask.gbs` 仅 22 个半孔开窗，全部为 1.4 × 2.0 mm 椭圆，无其他内部开窗、线段或填充区域。
- 底板 `*-F_Mask.gts` 中，模块板体范围内仅 22 个 M1 焊盘开窗，没有其他器件焊盘或过孔开窗中心；结合实际 PCB 的焊盘边界检查，没有其他裸铜开窗侵入覆盖区。

因此 **KiCad 这一套制造源**没有额外内部裸铜贴合点。制造与手焊时仍应保证覆膜、模块底面清洁和平整，不能用这一结果替代到货目检。原生另导出的 Gerber 需单独验证，不继承本条结论。

## DRC 异常解释与证据时效

最终核心 KiCad 检查文件为 `cad/core-output/silk-drc.json`：22 项 `copper_edge_clearance`，全部属于 J1 半孔焊盘；未连接项 0。

最终[核心原生工程](https://pro.lceda.cn/editor#id=468318639f18467982c3c48eda5f8e33)的证据为 `native-evidence/core-final-export.json` 和 `native-evidence/core-final/native-final-audit.json`，PCB DRC 为：

- 22 项 `Board Outline to TH Pad`；
- 22 项 `Board Outline to Hole`；
- 对象仅 J1_1…J1_22；原生原理图 `schDrc=[]`。

这些是明确为金属化半孔设计的焊盘/孔与板边相交，不属于意外铜线越界。不能全局忽略其他对象的板边规则，也不能据此推断制板厂已经接受半孔工艺。

底板最终 `cad/carrier-output/silk-drc.json` 为 0 项违规、0 项未连接。最终[底板原生工程](https://pro.lceda.cn/editor#id=046552eae5ca4c32aa83c7cad8f8930f)的证据为 `native-evidence/carrier-release-export.json` 和 `native-evidence/carrier-final/native-final-audit.json`，确认原生 PCB DRC 为 0；原理图 API 返回 5 条 warning，对应：

| 预留网络 | 底板唯一引脚 | 解释 |
|---|---|---|
| NRST | M1.7 | 模块复位预留 |
| SWDIO | M1.8 | 模块调试数据预留 |
| SWCLK | M1.9 | 模块调试时钟预留 |
| BOOT0 | M1.10 | 模块启动选择预留 |
| AUX | M1.22 | 模块扩展预留 |

这些网络在底板不接第二个器件是当前接口设计的有意保留，并非遗漏应连接的电气支路。原生 UI 另有 1 条 USB 空编号机械 NPTH 信息；PCB 网表共 138 条引脚记录，其中 137 条为电气引脚，剩余 1 条为 J1 空编号、无网络机械记录。审计单独排除该机械项后，原理图与 PCB 的电气网络逐针一致。U13.2 已在原生封装中确认为 GND 且连接方式为 `DIRECT`，不以仅有网名代替实际连接方式检查。
