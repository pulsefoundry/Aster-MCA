# v0.4 CAD / CAM visual review

2026-11-12. Reviewed both sides of both boards from actual exported Gerber/Excellon using Gerbonara; not only the schematic-derived placement preview. Current source fingerprints are in each `prototype-fabrication/source-hashes.json`.

- Core: two rows of 11 plated 0.8 mm drill hits intersect the long board edges exactly; copper rings exist on both sides, no castellated-pad paste apertures. A rectangular board outline through hole centers is deliberate. The exception is confined to these 22 pads. No separate component or signal trace was accepted as an edge exception.
- Carrier: the 22 module lands are top-side SMD lands, not holes. Their 2 mm pitch and 20 mm row spacing match the core. Each 2.8 mm long land extends 1.4 mm beyond the module edge, giving an accessible soldering toe. No carrier components are underneath the module. Core bottom has no components.
- The board-edge ground copper in the CAM image maintains its setback except at the intended core halfholes. The bottom carrier ground has no intentional moat around the hold node. Top copper keeps the specified local relief near the hold capacitor. These observations do not establish analog noise performance.
- USB shell slots remain plated routed slots, not round holes; USB locating holes are NPTH. The SMA pattern has five physical through holes, with the four shield pins sharing one electrical pin number. No extra drill file repeats vias.
- Necessary assembly silk was added with root authorization: core pin 1 triangle/number, USB direction, PWR/RUN, BOOT and NRST; carrier pin 1, module direction, USB, SMA, G–S–G and U10/U11/U12/U13 identifiers. Two core footprint line segments were moved from silk to documentation to make space. Updated KiCad checks found no silk-height, overlap or mask-clipping violations. All labels are at least 0.8 mm high. Minor passive references remain in the separate placement drawing rather than cramped on the board.
- Hand assembly is feasible with magnification, but 0402 passives and 0.5 mm-pitch MCU/MSOP are less forgiving than the previous 0603-heavy layout. The module orientation now has both explicit silkscreen and a geometric pin-1 marker. Pre-tinning all lands heavily would prevent flat seating; use two opposing tack joints first and verify alignment.
- The SMA is now a vertical five-pin 5.08 mm-pattern jack. The previously used edge-clamp SMA is not mechanically interchangeable. The USB connector also requires exact mechanical matching, including locating columns and shell tabs. These are procurement fit checks, not reasons to alter the validated drill geometry casually.

After the silk update, `silk-drc.json` contains only the core's 22 intentional KiCad halfhole-to-edge findings and no carrier findings; both have zero unconnected items. Native EDA results are separately recorded by the main agent. The EPRO/KiCad copper records, pin-to-pad networks and pad geometry were compared again after the final core schematic-note correction; all match.

The final core schematic notes were corrected to reset-to-BASE (nominal 0.623 V), positive peak minus pre-event RAW baseline, and rising-edge TRIG. This changed neither PCB geometry nor copper. No measured analog response, USB signal integrity, firmware operation or spectral resolution is claimed by this review.
