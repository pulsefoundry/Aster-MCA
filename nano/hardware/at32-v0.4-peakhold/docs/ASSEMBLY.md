# Aster MCA Nano AT32 v0.4 两板装配说明

本文件对应 **AT32 邮票孔模块＋峰值保持底板**的当前设计。这里的尺寸与孔位来自设计文件，尚未完成实物连接器配合及模拟性能验证；制造是否放行以本次最终检查记录为准。

## 两板关系

| 项目 | 当前设计 |
|---|---|
| AT32 模块 | 26 × 20 mm，双层；元件全部在顶面，底面保持平整 |
| 峰值保持底板 | 60 × 32 mm，双层，设计板厚1.6 mm |
| 模块在底板的位置 | 模块中心(21,16) mm，覆盖区域x8–34/y6–26 mm |
| 连接方式 | 模块两条长边共22个金属化半孔，孔径0.8 mm、节距2.0 mm；底板为对应SMD焊盘 |
| 模块焊盘 | 1.4 × 2.0 mm，孔中心落在模块板框线上；当前阻焊开窗与铜焊盘等大，扩展0 mm，无锡膏开窗 |
| 底板焊盘 | 1.5 × 2.8 mm，无钻孔；与模块半孔中心逐一对齐 |

模块正面元件朝上，焊在底板的正面。模块覆盖区不装底板元件；不要在模块底面留下锡珠或凸起。上下两板的裸铜、过孔与阻焊状态应按最终生产文件检查，避免模块底面与底板意外接触。

编号沿板周顺时针：上排从左到右1→11，下排从右到左12→22。底板M1使用相同编号和信号。焊接前先对照1脚、5V、GND和右下角模拟信号，确认没有将模块翻面或旋转180°。

VBUS是正常5V输入；模块LDO产生3.3V并从6脚供给底板。USB供电时不要再从6脚或SWD电压参考线注入另一组3.3V电源。

## 推荐手焊顺序

1. **分别焊两块板上的小件。**模块先焊AT32、LDO和小阻容，再焊BOOT、LED。底板先焊运放、模拟开关、比较器、二极管和阻容。按最终BOM区分DNP，不因存在焊盘就全部补齐。
2. **检查方向与锡桥。**尤其检查AT32的1脚、运放/模拟开关引脚、USB保护器件，以及峰值保持两颗二极管。保持电容附近尽量清洁，清除助焊剂残留和金属碎屑。
3. **检查模块底面和底板覆盖区。**保证平整，没有元件、凸起锡珠或夹入物。对照22个半孔的信号与编号。
4. **装模块M1。**先轻固定两个对角焊点，核对边缘平行和焊盘居中；确认后逐个焊接半孔。底板伸出的焊盘用于烙铁接触，检查每个半孔侧壁与底板焊盘之间确实形成焊锡连接。
5. **最后安装USB和SMA。**机械固定焊脚要充分润湿，插拔力由壳脚／地脚承担。若用外购SMA引线，选择J3的G-S-G孔，线尽量短，信号旁边带地线。
6. **断电检查。**核对5V和3.3V对地阻值、连接器引脚、所有模块半孔连续性和相邻焊盘锡桥。不要以电源灯能亮代替USB数据脚连续性检查。
7. **首次上电时SMA不接探头。**先检查3.3V供电，再检查底板参考电压是否接近设计值约0.623V。该值是设计预期，不是已经测得的结果。峰值保持控制、静态输出和ADC读数随后按专用固件逐项验证。

两颗蓝色0603 LED及其1kΩ限流电阻保持原方案。LED封装1脚为阴极K、2脚为阳极A；以最终装配图和万用表二极管档核对，不只凭灯珠外观猜测极性。

## USB-A 接头配合限制

J1采用原来的 **CnC Tech1001-011-01101 USB-A公头封装基准**。封装包括四个信号焊盘、两个金属化外壳长槽和两个非金属定位孔。外购替代件需核对信号脚位置、外壳固定脚、定位柱和板边位置；同为USB-A公头不代表焊盘兼容。

当前USB信号经过底板D90（USBLC6-2SC6）再到模块。D90是USB保护器件，不能与模拟电路D10混淆。C90和C91为机械/USB部分电容；模拟部分使用C100及之后的位号。

## 五针SMA与焊线口

J2采用 **KiCad SMA_Amphenol_132134_Vertical** 作为五针直立座的机械基准，不要求购买该品牌原件：

- 中心一脚为信号，钻孔1.5 mm。
- 四个地脚在5.08 × 5.08 mm方阵四角，即相对中心x/y各±2.54 mm，钻孔1.7 mm。
- 选替代品时需检查脚距、脚截面、中心脚位置、插入长度及外壳尺寸；“五针SMA”这一名称不足以证明兼容。
- 直立通孔结构没有旧式夹板SMA的夹板间隙问题，但仍需实际核对连接器在1.6 mm底板上的装配长度和焊接空间。

J3另留G-S-G三孔，节距2.54 mm、钻孔0.9 mm：1脚GND、2脚信号、3脚GND。可用于现有SMA座短引线接入。J2与J3连接同一输入，使用其中一种接法；不要同时接两台主动输出设备。输入只接探头已有放大/整形器的低压信号，不接探测器高压端。

## 本版信号方向与固件约定

底板把外部负脉冲转换为围绕约0.623V基线的**正向RAW脉冲**，然后保持正峰。幅度按 **PEAK_ADC－事件前RAW_ADC基线**计算。BASE_ADC只监测参考电压，不能直接代替事件前基线。

TRIG为高有效，采用上升沿。HOLD高时冻结捕获，PEAK_RESET高时将保持电容复位到BASE；底板上拉电阻使MCU复位期间保持安全默认。旧版v0.8.2固件不具备这套控制流程，需要本版适配固件，不能靠运行灯闪烁判断峰保功能已经工作。
